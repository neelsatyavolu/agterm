# What's New Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** After agterm updates, a new tab opens and plays the changelog for the versions you skipped, terminal style. agterm → What's New… shows it any time.

**Architecture:** `CHANGELOG.md` in the repo is the single source: it's bundled into the app and it also feeds the GitHub release notes. AgTermCore parses it and picks the unseen releases. An app-side renderer turns them into ANSI text. A What's New tab feeds that text into a fresh terminal line by line (a quick typed-out reveal), then leaves an ordinary shell prompt underneath so the tab stays useful.

**Tech Stack:** Swift 5.10, AppKit, SwiftTerm, XCTest.

**Spec:** the user's request: "add a what's new (with the changelog when updated) that's super cool and opens in a new terminal tab and is terminal style changelog".

## Global Constraints

- Colors come from the active theme's ANSI palette (indexed SGR 30–37/90–97), so every theme, Paper included, stays readable. No hard-coded RGB.
- Shows automatically only on an update (a stored last-seen version exists and is older than `CFBundleShortVersionString`). It never shows on first install or in self-tests.
- Copy follows `~/ANTI AI WRITING.md`: plain, specific, no hype.

## Review Focus

1. **Skipped several versions.** Expected: every release newer than last-seen, newest first. → Task 1 `testUnseenSpansSkippedVersions`.
2. **Version compare is numeric** (`1.0.10` > `1.0.9`). → Task 1 `testVersionsCompareNumerically`.
3. **Narrow window.** Expected: bullets wrap with a hanging indent under the bullet, no broken box art. → Task 2 `testWrapsWithHangingIndent`.
4. **Changelog missing from the bundle (dev build).** Expected: the menu item opens a tab saying the changelog wasn't found. It never crashes. → Task 3 self-test.
5. **Typing while it plays.** Expected: the reveal finishes immediately and the shell gets the keys. → Task 3.

**Interfaces:**

### Task 2: Terminal-style renderer

**Files:**

- Test: renderer logic that needs no AppKit goes in `Sources/AgTermCore/ChangelogRender.swift` + `Tests/AgTermCoreTests/ChangelogRenderTests.swift`

**Interfaces:**
- Produces: `public enum ChangelogRender { static func lines(_ releases: [Release], columns: Int) -> [String] }`: ANSI lines.
